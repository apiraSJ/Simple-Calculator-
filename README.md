# Simple Calculator

A modern, responsive web calculator built with HTML, CSS, JavaScript, and Bootstrap 5.  
Supports basic arithmetic, keyboard input, calculation history, and result copying.

## Live Demo

[https://apirasj.github.io/Simple-Calculator-/](https://apirasj.github.io/Simple-Calculator-/)

## Features

- Basic arithmetic: addition (+), subtraction (−), multiplication (×), division (÷)
- Decimal point support with duplicate guard
- Backspace (⌫) and Clear (C)
- Keyboard support (0–9, + - * / ., Enter, Backspace, Esc)
- Calculation history panel (saved in localStorage, max 20 entries)
- Click history entries to reuse past results
- Copy result to clipboard (with fallback)
- Comma grouping for large numbers (e.g. 1,000,000)
- Auto font-resize for long numbers
- Clean UI with smooth animations
- Responsive layout

## How to Use

1. Open index.html directly in any web browser
2. Click buttons or use your keyboard to calculate
3. View past calculations via the "History" button
4. Copy results with the "⧉ Copy" button

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Bootstrap 5.3.8
